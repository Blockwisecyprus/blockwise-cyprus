# BlockWise Cyprus website

This folder is a static website designed for free hosting on GitHub Pages.

## Included
- Home page
- Property Care page
- Building Administration page
- Our Approach page
- About page
- Contact / enquiry page
- English / Greek language switch
- Mobile-responsive design
- WhatsApp and phone links
- Contact form configured to send enquiries to `blockwisecyprus@cytanet.com.cy` through FormSubmit
- Draft privacy page
- Local SVG logo and illustrations, no paid image licences or external font subscriptions required

## Important before publishing
1. Confirm the exact domain spelling you purchased. Do not create a `CNAME` file until you confirm whether the domain is `blockwisecyprus.com` or another spelling.
2. Upload all files and the `assets` folder to the root of your GitHub repository.
3. In GitHub, open **Settings > Pages** and publish from the `main` branch, root folder.
4. Test the contact form once on the published site. FormSubmit will email `blockwisecyprus@cytanet.com.cy` asking you to activate the form. Click the activation link. FormSubmit states that first use requires email confirmation.
5. After your domain is confirmed, add it under **Settings > Pages > Custom domain**, then configure the DNS records at your domain provider.
6. Review the privacy wording with a Cyprus legal/privacy adviser once the final company structure and data-processing arrangements are confirmed.

## GitHub Pages custom domain DNS
GitHub's current documentation says:
- Apex/root domain: add A records for `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
- `www` subdomain: add a CNAME pointing to `YOUR-GITHUB-USERNAME.github.io`.
- Add the custom domain in GitHub Pages settings before changing DNS.
- DNS changes can take up to 24 hours.
